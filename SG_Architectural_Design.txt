│                                                               │
│ Classify every atomic rule source:                            │
│ • SG reference                                                │
│ • IPv4 CIDR                                                   │
│ • IPv6 CIDR                                                   │
│ • Prefix list                                                 │
└──────────────────────────────┬────────────────────────────────┘
                               │
                               ▼
┌───────────────────────────────────────────────────────────────┐
│ 2. TRANSLATE                                                  │
│                                                               │
│ SG         → Discover target SG equivalent                    │
│ CIDR       → Determine network meaning and target equivalent  │
│ Prefix list→ Discover target prefix-list equivalent           │
│ Universal  → Preserve explicitly                              │
│ External   → Preserve only with sufficient routing evidence   │
│                                                               │
│ Output: Desired target atomic rules                           │
└──────────────────────────────┬────────────────────────────────┘
                               │
                               ▼
┌───────────────────────────────────────────────────────────────┐
│ 3. VALIDATE                                                   │
│                                                               │
│ Validate:                                                     │
│ • Match uniqueness                                            │
│ • Address family                                              │
│ • CIDR containment and relative offset                        │
│ • Route-role compatibility                                    │
│ • Dependency completeness                                     │
│ • Prefix-list identity                                        │
│ • Rule validity                                               │
│ • Target duplicates                                           │
│ • Apply policy                                                │
│                                                               │
│ HIGH confidence   → Eligible for apply                         │
│ MEDIUM confidence → Operator review                            │
│ LOW confidence    → Blocked                                   │

                               │
                               ▼

│ • Synchronize approved tags                                   │
│ • Preserve target-only rules                                  │
│ • Record rollback actions                                     │
